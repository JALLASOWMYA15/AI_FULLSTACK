# AI Personal Digital File Organizer
An AI-powered Streamlit application that automatically organizes personal files.
## Features
- Upload PDF, JPG, JPEG, PNG, TXT and DOCX files
- Multiple file upload
- PDF text extraction
- OCR for images and screenshots
- AI image classification
- Automatic document categorization
- Automatic tag generation
- Automatic title generation
- Automatic summaries
- Metadata extraction
- Semantic search
- ChromaDB vector database
- File preview
- Dashboard
- Category statistics
- Local file storage
## Categories
- College Notes
- Certificates
- ID Documents
- Assignments
- Bills/Receipts
- Screenshots
- Photos
- Projects
- Personal Documents
- Other
